# gema-project-demo
GEMA (Enterprise Maintenance Manager) is a full-stack web application developed as part of the Digital Transformation Challenge organized by the Government of Meta, Colombia.
The system enables companies to manage preventive maintenance for machinery, track operating hours, register photographic evidence, receive alerts, and control maintenance workflows.

This repository is a showcase of the project. It includes screenshots, feature explanations, and architecture documentation.
The source code remains private as required by the partnering company (SERVIMACONS SAS).
